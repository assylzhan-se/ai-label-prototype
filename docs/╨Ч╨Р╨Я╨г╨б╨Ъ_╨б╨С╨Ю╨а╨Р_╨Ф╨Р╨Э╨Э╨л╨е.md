# Запуск сбора данных (Assignment 4)

## 1. Обновить проект (один раз)
Распакуйте новый `ai-label-prototype.zip` поверх старой папки и согласитесь заменить файлы. Папка `.git` останется.
Затем в терминале, в папке проекта, с активированным `.venv`:
```
del data\study.db
```
Это удаляет старые демо-сессии. Если файла нет, ошибка не страшна.

## 2. Вставить настоящие лица
1. В папке `static\stimuli` удалите `P1.png` … `P6.png`.
2. Положите туда 6 своих файлов: `P1.jpg` … `P6.jpg` (подойдут также .png и .webp). P1, P3, P5 — девушки, P2, P4, P6 — парни.
3. Выполните:
```
python scripts\make_placeholder_stimuli.py --manifest-only
python -m pytest -q tests
```
Должно быть `10 passed`. Посмотрите все 6 профилей своими глазами: `python app.py`, затем `http://127.0.0.1:5000/?test=1`.

4. Сохраните версию:
```
git add .
git commit -m "Final stimuli, fixed tap targets (T6), analysis pipeline for Assignment 4"
git push
```

## 3. Запустить сбор
Окно 1:
```
python app.py
```
Окно 2:
```
cloudflared tunnel --url http://localhost:5000
```
Через несколько секунд появится ссылка вида `https://что-то.trycloudflare.com`. **Её и рассылаете участникам, без `?test=1`.**

Важно:
- ноутбук не закрывать и не выключать, подключить к зарядке, отключить спящий режим, оба окна держать открытыми;
- если окно 2 закрылось, ссылка поменяется: запустите туннель заново и разошлите новую ссылку;
- сами по ссылке участников **не проходите**. Для проверки используйте `http://127.0.0.1:5000/?test=1`.

## 4. Следить за ходом
В третьем окне:
```
python export.py
```
Команда покажет, сколько участников уже записано.

## 5. Закончить и получить результаты
Остановите оба окна (`Ctrl+C`), затем:
```
python export.py
python analysis\run_all.py --db data\study.db --out results
```
Заархивируйте папку `results` и пришлите её. В ней только коды участников, без имён.
Также запишите в журнал, когда начали и когда закончили, куда отправляли ссылку и сколько человек примерно получили приглашение.

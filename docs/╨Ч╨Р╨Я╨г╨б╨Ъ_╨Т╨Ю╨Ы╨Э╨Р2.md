# Запуск второй волны сбора данных (v4, под фидбек Assignment 4)

Что изменилось в v4:
- двухчастная проверка манипуляции: «Была ли метка?» и «Что на ней было написано?»;
- кнопка «Next profile» активна только через 10 секунд, сервер не принимает ответ быстрее;
- вопрос на внимательность (на 3-м профиле: «выберите 2»);
- пол спрашивается до распределения, рандомизация идёт отдельно по полу;
- повторное прохождение с того же браузера блокируется;
- после 6 основных ИИ-профилей идут 2 реальных фото со стока Unsplash (дополнительный блок, анализируется отдельно; в debrief это раскрыто);
- данные пишутся в новую базу `data\study_wave2.db`, старая `study.db` не трогается.

## 1. Обновить проект
Распакуйте архив поверх папки проекта (с заменой файлов), затем в cmd:
```
cd C:\Users\Admin\Downloads\ai-label-prototype\ai-label-prototype
.venv\Scripts\activate
python -m pytest -q tests
```
Должно быть `17 passed`.

## 2. Запуск
Окно 1: `python app.py`
Окно 2: `cloudflared tunnel --url http://localhost:5000` → новая ссылка `https://....trycloudflare.com`

## 3. Ссылки для рассылки (по источнику — так видно, откуда пришёл человек)
- для групповых чатов: `https://....trycloudflare.com/?src=chat`
- для личных сообщений: `https://....trycloudflare.com/?src=dm`

Правила:
- каждый проходит **на своём телефоне** по ссылке. Не давайте свой телефон другим людям;
- сами по ссылке без `?test=1` не проходите;
- никаких автоматических скриптов по живой ссылке.

## 4. Проверка хода
`python export.py --db data\study_wave2.db --out data\export_wave2.csv`

## 5. Когда закончите
```
python analysis\run_all.py --db data\study_wave2.db --out results_wave2
```
Заархивируйте папку `results_wave2` и пришлите.
